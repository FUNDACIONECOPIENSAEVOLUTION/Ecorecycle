# Auditoría visual ECORECYCLE · 25 de octubre de 2026

## Regla institucional
- El logotipo se toma exclusivamente de `logo ecopiensa (1).png`, sin modificarlo.
- **ECOALDEAS** = parcelaciones/fincas con familias y producción diversificada, no monocultivo ni diseño circular obligatorio.
- **ECO-CIA** = centro independiente de acopio, procesamiento, formación y distribución. Puede tener propuesta espacial circular.
- **ORGÁNICOS** = tratamiento especializado que puede aportar enmiendas agrícolas aptas a los cultivos de las ecoaldeas.
- Primero **autoconsumo**, luego **excedentes aptos → ECO-CIA → mercados y eco-tiendas**.
- Las imágenes públicas permanecen alojadas en GitHub Pages y se abren dentro de la misma web, no se enlazan directamente a bibliotecas externas.
- No se publica el proyecto macro completo ni información privada.
